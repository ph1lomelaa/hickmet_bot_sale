# 📅 OPEN DATE - Инструкция по использованию

## 🎯 Что такое OPEN DATE?

OPEN DATE - это функция для записи паломников без конкретной даты поездки. Паломники записываются в Google Sheets таблицу "Certificate 2025" и ждут, пока выберут дату.

## 📋 Как работает система?

### Сценарий 1: Заполнить паломника на OPEN DATE

1. **Менеджер открывает историю бронирований**
   - Нажимает кнопку **📅 OPEN DATE**

2. **Выбирает действие**
   - Нажимает **✍️ Заполнить паломника на OPEN DATE**

3. **Заполняет форму**
   - Выбирает количество паломников (1-10)
   - Заполняет обязательные поля:
     - Фамилия, Имя (латиницей)
     - Пол
     - Телефон клиента
   - Опционально заполняет:
     - Дата рождения
     - Номер паспорта
     - Срок действия паспорта
     - ИИН
     - Размещение (или "Не указано")
     - Питание (или "Не указано")
     - Цена
     - Город вылета
     - Регион
     - Комментарий

4. **Нажимает "📋 Записать в OPEN DATE"**

5. **Что происходит автоматически:**
   - ✅ Данные сохраняются в БД (таблица `open_date_bookings`)
   - ✅ Паломники записываются в Google Sheets "Certificate 2025"
   - ✅ Каждый паломник получает отдельную строку
   - ✅ Статус брони: **OPEN**

---

### Сценарий 2: Паломник выбрал дату

1. **Менеджер открывает историю бронирований**
   - Нажимает кнопку **📅 OPEN DATE**

2. **Выбирает действие**
   - Нажимает **📆 Паломник выбрал дату**

3. **Видит список всех OPEN DATE паломников**
   - Может использовать поиск по:
     - Имени/Фамилии
     - Номеру телефона
     - Номеру паспорта
     - ИИН

4. **Выбирает паломника**
   - Нажимает **📆 ВЫБРАТЬ ДАТУ** на карточке паломника

5. **Заполняет обычную форму бронирования**
   - Данные паломника уже предзаполнены
   - Выбирает дату и пакет
   - Выбирает размещение
   - Нажимает **✅ ЗАВЕРШИТЬ И ЗАПИСАТЬ**

6. **Что происходит автоматически:**
   - ✅ Создается обычная бронь в БД (таблица `bookings`)
   - ✅ Паломник записывается в таблицу размещения (выбранный пакет)
   - ✅ Паломник удаляется из Certificate 2025
   - ✅ Паломник записывается в лист "ИСПОЛЬЗОВАННЫЕ" с выбранной датой
   - ✅ OPEN DATE запись помечается как **CONVERTED**

## 🗂️ Структура файлов

### База данных

- **Модель:** `bull_project/bull_bot/database/models.py` (строки 103-136)
  - Таблица: `open_date_bookings`
  - Поля: manager_id, pilgrim_data (JSON), room_type, meal_type, price, client_phone, status, и др.

- **Функции:** `bull_project/bull_bot/database/requests.py` (строки 753-890)
  - `add_open_date_booking()` - создать OPEN DATE
  - `get_all_open_date_bookings()` - получить список
  - `get_open_date_booking_by_id()` - получить по ID
  - `search_open_date_bookings()` - поиск
  - `update_open_date_booking_status()` - обновить статус
  - `delete_open_date_booking()` - удалить
  - `update_open_date_booking_sheet_row()` - обновить номер строки

### Google Sheets

- **Функции:** `bull_project/bull_bot/core/google_sheets/writer.py` (строки 616-908)
  - `write_open_date_to_certificate()` - запись в Certificate 2025
  - `move_pilgrim_from_certificate_to_used()` - перенос в ИСПОЛЬЗОВАННЫЕ

- **Таблица:** [Certificate 2025](https://docs.google.com/spreadsheets/d/1IKLFtRq7tSTuU3dyVf8u0vhGswDBBh9rhj1R8B6WI8c/edit?gid=187784552#gid=187784552)
  - Лист: **Certificate 2025** - для OPEN DATE паломников
  - Лист: **ИСПОЛЬЗОВАННЫЕ** - для паломников, выбравших дату

### Frontend (HTML)

- **open_date.html** - главная страница выбора действия
- **open_date_form.html** - форма заполнения паломников
- **open_date_select.html** - список паломников для выбора даты
- **index.html** - обычная форма бронирования (с поддержкой OPEN DATE)
- **history_v2.html** - история с кнопкой OPEN DATE

### Backend (API)

- **Router:** `bull_project/bull_bot/api/routes/open_date.py`
  - 6 endpoints для работы с OPEN DATE

- **Endpoints:**
  - `POST /api/open-date/submit` - создать OPEN DATE
  - `GET /api/open-date/list` - список всех OPEN DATE
  - `GET /api/open-date/{booking_id}` - получить по ID
  - `GET /api/open-date/search?q=` - поиск
  - `POST /api/open-date/convert/{booking_id}` - конвертация в обычную бронь
  - `DELETE /api/open-date/{booking_id}` - удалить

## 📊 Статусы OPEN DATE

- **OPEN** - паломник ждет выбора даты
- **CONVERTED** - паломник выбрал дату и был конвертирован в обычную бронь

## 🐛 Отладка

### Консоль браузера

Все операции OPEN DATE логируются в консоль браузера:

- `📅 Конвертация OPEN DATE #123` - начало конвертации
- `✅ OPEN DATE успешно конвертирован` - успешная конвертация
- `⚠️ Ошибка конвертации OPEN DATE` - ошибка (бронь уже создана)

### Параметры URL

В `index.html` при открытии из OPEN DATE передаются параметры:

```
?open_date_id=123&pilgrims=[...]&phone=...&room_type=...&meal_type=...&mode=from_open_date
```

## ❓ Частые вопросы

**Q: Можно ли редактировать OPEN DATE запись?**
A: Пока нет, но можно удалить и создать заново.

**Q: Что если паломник не найден в Certificate 2025 при конвертации?**
A: Система выдаст предупреждение, но бронь все равно будет создана.

**Q: Можно ли отменить OPEN DATE?**
A: Да, через API endpoint `DELETE /api/open-date/{booking_id}`.

**Q: Сколько паломников можно записать в одну OPEN DATE бронь?**
A: От 1 до 10 паломников.
