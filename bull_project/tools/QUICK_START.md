# 🚀 Быстрый старт: Обработка 500 паспортов

## Шаг 1: Автоматическая разметка

Запустите автоматическую разметку вашего ZIP архива с 500 паспортами:

```bash
cd /Users/muslimakosmagambetova/Downloads/tired2\ 2/bull_project/tools

# Вариант 1: Используя готовый скрипт
./RUN_BATCH_ANNOTATION.sh /path/to/your/passports.zip

# Вариант 2: Напрямую через Python
python3 auto_annotate_batch.py \
    --input /path/to/your/passports.zip \
    --output passport_dataset.json
```

**Что произойдет:**
- 📦 Распакует ZIP архив
- 🔍 Найдет все паспорты (PDF, PNG, JPG)
- 🤖 Автоматически распарсит каждый паспорт
- 📊 Рассчитает уверенность для каждого результата
- 💾 Создаст два файла:
  - `passport_dataset.json` - ВСЕ паспорты (готов для обучения)
  - `passport_dataset_review_only.json` - Только те, что требуют проверки

**Время выполнения:** ~30-60 минут для 500 паспортов

## Шаг 2: Анализ результатов

После завершения вы увидите статистику:

```
📊 СТАТИСТИКА АВТОМАТИЧЕСКОЙ РАЗМЕТКИ
Всего обработано:     500
✅ Успешно (conf≥85%): 425 (85%)
⚠️  Требуют проверки:   65 (13%)
❌ Ошибки:             10 (2%)
```

**Что значат эти цифры:**

- **Успешно (85%)** - Эти паспорты готовы для обучения модели
- **Требуют проверки (13%)** - Откройте `passport_annotator.html` и проверьте эти 65 паспортов
- **Ошибки (2%)** - Возможно плохое качество сканов, нужна ручная разметка

## Шаг 3: Ручная проверка (опционально)

Если хотите улучшить качество:

1. Откройте `passport_annotator.html` в браузере
2. Загрузите `passport_dataset_review_only.json`
3. Проверьте и исправьте паспорты с низкой уверенностью
4. Скачайте исправленный датасет

**Время:** ~10-15 секунд на паспорт = ~15 минут для 65 паспортов

## Шаг 4: Обучение модели

Когда датасет готов:

```bash
python3 train_passport_model.py \
    --dataset passport_dataset.json \
    --output ../models/passport_model \
    --epochs 3 \
    --batch-size 16
```

**Требования:**
- GPU (или используйте Google Colab - бесплатно)
- 16GB RAM
- ~1-2 часа обучения

**Для Google Colab:**
1. Загрузите `passport_dataset.json` на Google Drive
2. Откройте [Google Colab](https://colab.research.google.com/)
3. Следуйте инструкциям в `ML_TRAINING_GUIDE.md`
